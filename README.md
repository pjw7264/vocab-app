# 영단어 암기용 프로그램

단어장 사진이나 텍스트를 넣고 단계별로 외우는 단일 파일 웹 앱 (`index.html`).

- **1-1** 발음 보고 뜻 보기 (카드) · **1-2** 듣고 뜻 맞추기 (4지선다, 영어 음성)
- **2-1** 타이핑 테스트 (랜덤 / 순서대로, 10초) · **2-2** 짝 맞추기 (5쌍, 20초)
- 틀린 단어 모아보기 · 오답 재도전 · 학습 기록 (자주 틀린 단어, 백업/복원)
- 단어장 추가: 사진(OCR) 또는 텍스트 (`word 뜻`, `word [발음] 뜻`, `word | 발음 | 뜻`)

**바로 열기: https://pjw7264.github.io/vocab-app/** (폰에서도 돼요)

`index.html`을 브라우저로 열어도 실행돼요. 기록은 그 브라우저에 저장돼요.
